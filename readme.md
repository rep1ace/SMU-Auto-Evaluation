# 南方医科大学自动评课

一个常驻 Windows 系统托盘的自动评课工具。安装后无需打开命令行，程序会随 Windows 登录自动启动，并在每天设定的时间检查当天与前一天的待评课程。

## 普通用户：一键安装

1. 从项目 Releases 下载 `南医自动评课-安装程序.exe`，双击并按向导安装。
2. 安装完成后程序会出现在右下角系统托盘；首次启动会自动打开设置。
3. 填写统一身份认证账号、密码和每日运行时间，点击“保存”。

关闭设置窗口不会退出程序。右键托盘图标可以立即运行、修改设置、打开日志或退出。配置和日志保存在 `%APPDATA%\SMU Auto Evaluation`，不会因升级或卸载程序文件而丢失。若暂时看不到图标，请在任务栏的“隐藏的图标”中查找。

> 凭据仅写入当前 Windows 用户的本地配置文件，不会发送到教务系统之外的服务。现有密码存储采用 Base64 编码，并非加密；能够读取配置文件的人可以还原密码。请保护好 Windows 账户及配置目录权限，不要分享配置文件。日志不记录原始登录响应、验证码或 SSO 票据。

## 工作方式

- 使用统一身份认证登录，内置 ONNX 模型自动识别验证码。
- 每天按设置时间查询当天和前一天尚未评价的课程。
- 所有评课时间按北京时间（UTC+8）计算，不依赖电脑所在时区。每门课以教务系统的 `jksj` 结束时间为准；尚未结束的课不提交。时间缺失或无法解析时也不提前评价，而是保留待处理状态并写入日志。
- 未结束的课程会安排在课程结束后 **1～15 分钟的随机时间**再检查；已经生成的时间会保存，重复查询或重启不会重新抽取。若课程结束时间被教务系统修改，则重新安排。手动“立即运行”也会更新同一账号的课程进度，并保留已经安排的重试时间。
- 每天在 **19:00～19:30 的随机时间**独立查询一次实际评课状态，存在待评课程时进行兜底评课。即使早晨查询为空或普通每日任务已经用完失败重试次数，也保留此检查；已完成的课程不重复提交。晚于 19:00 结束的课仍须等下课后再评价。每门课的成功记录、待处理状态、课后重试时间和晚间兜底时间均保存到本机磁盘，按账号隔离。
- 每日任务、课后重试和晚间检查各自记录执行状态；网络失败每个任务最多延迟重试两次，间隔 15 分钟。同一轮中一门课提交失败不影响其他已结束的课。提交前在随机等待结束后重新查询，防止课程延期或已在其他浏览器评完；提交后须查询到对应课程的明确已评状态才计入完成。查询遗漏、失败或分页不完整时，不清除已保存的待处理记录；提交请求超时不会立即盲目重发。
- 不同课程的提交请求串行执行，提交起点之间至少保留随机 **30～60 秒**间隔；间隔也跨重启保存。登录、验证码、查询与提交使用一致的 Chrome UA 和相应请求头，Cookie 由同一会话维护。HTTP 请求无法完整复现真实浏览器指纹，也不能保证网站不会识别自动化。
- 在当天计划时间之后启动，会补跑尚未完成的任务；重启后在取得账号运行锁、确认没有旧进程工作时，立即恢复中断任务；关机或退出期间不能执行，到再次启动时补检查。不会逐日重放长期停机期间的任务。使用自动重试须保持托盘程序运行，建议启用开机自启动；`python main.py` / `run_evaluation()` 仍为一次性调用，共享课程进度，但不驻留调度。
- 网络或登录错误会写入日志，并通过 Windows 通知提示；托盘进程继续运行，下一天会再次尝试。
- 安装程序使用当前用户权限安装，并通过 Windows `Run` 启动项实现无黑框自启动。

状态文件位于 `%APPDATA%\SMU Auto Evaluation` 的 `evaluation-<账号摘要>.json` 与对应的 `.schedule.json`，采用原子替换与落盘同步，保留最近七天记录，状态文件不含密码。请勿删除当日状态文件，否则会失去本机进度；服务器返回的评课状态仍会在提交前检查。

## 开发与构建

要求 Python 3.11+ 与 [uv](https://docs.astral.sh/uv/)。

```powershell
uv sync --group dev
uv run pytest
uv run python tray_app.py
```

生成免 Python 环境的一键安装包还需安装 Inno Setup 6，然后在 PowerShell 执行：

```powershell
./build.ps1
```

产物位于 `dist-installer`。推送 `v*` 标签或手动运行 GitHub Actions 中的 **Build Windows installer** 也会构建可下载的安装包。

项目内置验证码模型；源码运行时请保留 `models/captcha_model.onnx` 与 `models/captcha_model.onnx.data`。
